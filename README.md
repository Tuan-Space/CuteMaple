# 🍁 CuteMaple · 美腻枫桌宠

一只住在 Windows 桌面上的 Live2D 小伙伴，陪你工作、学习，也陪你发会儿呆。✨

<p align="center"><img src="assets/master/美腻枫_标准立绘_v1.png" alt="美腻枫" width="280"></p>

## 🎀 她会做什么？

- 👀 **看向鼠标**：头部和眼睛自然跟随，偶尔眨眨眼。
- 🖱️ **点击与抚摸**：单击说话、双击打开手账，在头部来回轻扫就能摸摸头；荡秋千时也可以抚摸。
- 🪂 **拖动与下落**：按住拖到喜欢的位置，松手后落回桌面。
- 🧗 **贴边攀爬**：拖到屏幕左右边缘，休息 30 秒后连续爬两次；休息时仍会看向鼠标。
- 🎠 **顶部秋千**：爬到顶部，或直接拖到顶部，就能坐上秋千。
- 💤 **睡觉与散步**：闲下来会休息，也可以在菜单里开启自主行走。
- ⌨️ **打字回应**：感受到键盘活动时，用小动作和光点陪伴你。
- 🎵 **声音回应**：随着电脑播放的声音侧耳、点头，冒出小音符。
- ✨ **装饰特效**：枫叶、星光、爱心、气泡、花瓣等小惊喜，可在菜单中开关。

## 📊 桌面小助手

- 查看 **内存占用、上传与下载速度、累计流量及当前网卡**。
- 简洁面板和详细面板随 Windows 的浅色／深色应用主题自动换装。🌗
- 支持手动清理内存，也可设置自动清理条件；每次启动后首次手动清理需要确认系统授权。
- 支持暂停、隐藏、尺寸调整、多屏摆放和开机启动。

## 🍂 枫叶手账

双击人物，或从右键菜单打开手账：

- 💧 **健康小提醒**：按自己的节奏提醒喝水、走动、看远处。默认关闭，回应后才重新计时，可查看日、周、月、年记录。
- 📅 **事件与纪念日**：一次性或重复提醒，支持农历、提前提醒和稍后再提醒；错过的提醒会集中整理。
- 💜 **纪念日里程碑**：记下起始日期，选择每周年、每 100 天、520 天、1314 天或自定义天数。起始当天算第 1 天。
- 📝 **随手记笔记**：直接编辑排版后的文字，支持三级标题、粗体、斜体、删除线、列表与层级、引用和链接，也能切换 Markdown 源码。右下角“＋”可添加附件或录音，删除后可从回收站恢复。
- 🗓️ **总览日历**：待办、日程、纪念日、笔记和健康记录各有一种小圆点；支持年月切换、农历节日和休班标记，节假日可手动更新。
- 🗑️ **放心整理**：已完成提醒与回收站分开，删除的提醒和笔记可恢复，也可在回收站彻底删除。
- 📖 **清楚好读**：浅蓝纸页与深色主题，内置字体标题、分类标记和逐条分隔；小窗口可以纵向展开，录音播完后点击外部即可收起播放器。
- 📁 **资料自己保管**：首次打开选择资料文件夹，也能打开已有资料库；支持导出包含附件的完整备份。

提醒气泡需要手动回应，不会自动消失。隐藏人物后仍会提醒；退出软件或电脑休眠时不会唤醒电脑，重新打开后会整理错过的事件。

## 🚀 开始陪伴

1. 下载 **Setup-x64.exe 安装程序**，按提示选择安装位置、快捷方式和是否开机启动。
2. 第一次打开时，新建资料库或选择已有资料文件夹。
3. 单击人物聊天，双击打开手账；右键人物或托盘图标调整设置。

后续运行新版安装程序即可覆盖升级，个人资料继续保留。设置页面可检查更新并打开下载页面。

从旧解压版首次转为安装版时，请先从托盘退出旧版，再启动新程序。

💡 按住 `Ctrl` 滚动鼠标滚轮可调整人物大小。

## 🔒 安静陪伴

桌宠与个人资料在本机运行。打字回应只检测活动，不读取输入内容；声音回应只检测播放音量。**只有你在笔记中主动开始录音时才使用麦克风**，界面会显示录音状态。播放声音时，桌宠会保持清醒。
