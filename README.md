# CuteMaple｜美腻枫桌宠 🍁

一只会走路、爬屏幕、荡秋千、回应抚摸，还能顺手查看电脑状态的 Windows 桌面伙伴。

## 功能一览

- 🎞️ 透明置顶桌宠与连续动画：待机、行走、拖动、下落、着地、攀爬、秋千、睡眠、对话、开心与抚摸反馈。
- 🖱️ 自然桌面互动：单击、双击、拖放、头部轻扫与 `Ctrl + 鼠标滚轮` 缩放。
- 🧭 屏幕边缘玩法：拖到左右边缘后攀爬，拖到顶部或爬到顶部后荡秋千。
- 💤 全系统空闲睡眠：连续 60 秒无键鼠输入后入睡，输入恢复或睡满 4 分钟后自然醒来。
- 📊 本机性能监控：查看实时下载/上传速度、内存占用、活动网卡与本次运行累计流量。
- 🧹 按需内存清理：手动或按时间、内存阈值自动触发，并播放与当前位置匹配的清理动画。
- 🖥️ 多显示器与托盘支持：记忆位置、显示或隐藏、暂停、调整尺寸和设置当前用户开机启动。
- 🔒 离线运行：资源监控与清理均在本机完成，不联网、不上传指标。

## 功能详解

### 🍁 桌宠与动画

桌宠使用透明、始终置顶的无边框窗口显示。她会在当前屏幕底部随机待机和往返行走；普通行走碰到边缘时会折返，不会误触发攀爬。

- 左键单击：随机说一句陪伴台词。
- 左键双击：播放开心动作，并显示一条独立的积极鼓励台词。
- 按住左键拖动：根据移动方向切换拖动姿势。
- 悬空释放：先轻飘下落，接触屏幕底部后播放一次着地动画。
- 鼠标在头部区域来回轻扫：触发带冷却时间的抚摸反馈。

### 🧗 边缘攀爬与秋千

把桌宠主动拖到屏幕左侧或右侧，她会贴着边缘上下攀爬；把她拖到屏幕顶部，或让她从侧边爬到顶部，则会先前后荡三轮秋千，随后坐在秋千上缓慢呼吸和眨眼。

### 💤 空闲睡眠

Windows 全系统连续 60 秒没有键盘或鼠标输入时，桌宠会连贯地坐下并入睡。任意输入会唤醒她；如果一直没有输入，她也会在睡满 4 分钟后自行醒来。攀爬和顶部秋千状态不会被地面的随机行为或睡眠打断。

### 📊 性能监控

鼠标靠近桌宠时会出现浅蓝色性能按钮：

- 悬浮按钮：显示实时下载速度、上传速度和内存占用。
- 单击按钮：打开详细面板，查看内存、网卡和累计流量。
- 双击按钮：立即执行内存清理。
- 右键桌宠、性能按钮或托盘：可常显监控数据、打开详细面板、立即清理或配置自动清理。

所有采样都在本机进行，默认每 2 秒刷新一次。

### 🧹 内存清理与自动清理

首次运行当前版本时，程序会请求一次 UAC 授权，用于创建当前用户的高权限按需计划任务 `美腻枫_内存清理`。桌宠主进程始终以普通权限运行；拒绝授权不会影响桌宠和性能监控。

自动清理默认关闭，可选择：

- 每 15 / 30 / 60 / 120 / 240 分钟清理；
- 物理内存占用达到 60%～95% 时清理；
- 两次清理至少间隔 10 分钟。

清理结果展示“可用内存变化”，不承诺固定释放量。为减少卡顿与重新读盘，程序不会清理完整待机列表和修改页列表。

### ⚙️ 托盘、尺寸与开机启动

右键桌宠或托盘图标可以显示/隐藏桌宠、暂停/继续活动、选择小/默认/大尺寸、恢复默认大小、设置开机启动或退出。也可使用 `Ctrl + 鼠标滚轮` 连续缩放。

“暂停活动”会冻结动画、位移和抚摸响应；暂停时仍可拖动桌宠改变位置，继续活动后才恢复下落、攀爬等状态。

## 下载与使用

1. 在仓库右侧的 **Releases** 中下载 `CuteMaple.exe`。
2. 双击运行，无需安装 Python。
3. 若 Windows SmartScreen 提示未知发布者，请确认文件来自本仓库 Release 后再决定是否运行。

当前为未签名单文件程序，首次启动需要释放运行文件到系统临时目录，通常会等待数秒。Release 同时提供 SHA-256 校验值。

## 从源码运行

需要 Windows 与 Python 3.11+：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:MEINIFENG_DISABLE_AUTOSTART = "1"
.\.venv\Scripts\python.exe main.py
```

开发时设置 `MEINIFENG_DISABLE_AUTOSTART=1`，可以避免修改当前用户的启动项。

## 测试与构建

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe -m pytest -q
.\build.ps1
```

构建结果位于 `dist\美腻枫.exe`。构建脚本使用 Nuitka 生成无压缩 onefile 包，以降低安全软件拦截构建负载的概率。

## 素材说明

仓库只保留当前版本所需的素材链：

- `assets/master`：角色标准立绘；
- `assets/source_*`：处理脚本实际使用的原始动作源图；
- `assets/sprites_v2`：程序运行时使用的最终透明 PNG 帧；
- `assets/previews`：README 使用的少量最终动画预览；
- `assets/fonts` 与图标文件：运行和构建所需资源。

早期版本、未采用源板、旧精灵和中间检查图未纳入本仓库。

## 隐私说明

CuteMaple 不包含联网功能。设置、崩溃日志、清理请求与结果均保存在当前用户的 `%APPDATA%\美腻枫` 目录中。
