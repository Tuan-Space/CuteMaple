# 美腻枫 v5.1 动作优化版

完整解压 ZIP，打开目录内的 `CuteMaple-Live2D.exe`。请保留旁边的 `assets`、`web`、`cleaner` 和依赖文件；分享时发送整个 ZIP。先退出正在运行的旧版，再启动新版。现有个人设置沿用，v4、v5 文件与入口保留。

## 本轮动作

拖动、下落和落地使用垂落长袖与连续收手动作；攀爬改为每秒一次完整换手周期，并调整屈膝处裙褶、裤腿和承重关系。秋千使用连续摆动节奏，大摆、轻摆和顶部清理之间平滑衔接。

清理改为取出小刷子、在腰外侧短弧扫尘、收回刷子。墙边保留承重手，顶部保留一手握绳。尘点跟随刷毛端；完成闪光取决于真实清理结果。

## 秋千抚摸

人物在秋千上时，不按鼠标键，在头发或脸部区域左右来回移动鼠标。与地面抚摸使用相同手势：约 1.5 秒内往返两次，移动幅度要足够。触发后轻摆、闭眼蹭头约 3 秒，双手继续握绳；两次触发间隔至少 6 秒。

清理、暂停、隐藏或开始拖动会结束本次抚摸。命中区域跟随当前头部位置，长发尾和丝带不计入头部区域。

## 互动与清理

右键 → **互动**，可开关打字回应、系统声音回应和装饰特效。**互动检测与效果预览**显示输入检测状态、系统输出音量及逐项效果预览。预览只展示效果，真实输入以检测状态为准。风纹已移除；尘点只在有清扫工具位置时预览。

右键 → **性能与内存 → 立即清理内存**。清理步骤、结果和失败详情在气泡及性能面板显示。重复点击继续显示同一次操作，不覆盖请求。

如果之前授权指向旧版清理助手，使用 **性能与内存 → 修复清理授权…**，按 Windows 提示确认。新版打包不会自动迁移旧授权，也不会在启动时自动弹出授权。

## 暂停拖放

选择“暂停活动”后仍可拖动人物。左右边缘显示静态攀爬，顶部显示静态秋千，角落优先顶部；松手后仍保持暂停。选择“继续活动”恢复。

## 验证范围

本轮自动检查、原生模型连续画面和最终目录包启动结果见随包的 `USER-TEST-HANDOFF.json`。实际 ToDesk 手势、系统声音、真实清理和长时间桌面使用按约定由你自测；这些项目不以自动预览代替。
