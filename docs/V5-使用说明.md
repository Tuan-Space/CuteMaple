# 美腻枫 v5 使用说明（验收中）

当前源码仍在验收，尚无通过全部检查的 v5 分享包。继续保留 v4 程序及 ZIP；不要把构建目录中的单个 EXE 当成完整安装包。

## 打字和声音回应

右键桌宠 → **互动**，打开“打字回应”“系统声音回应”“装饰特效”。正常打字会触发注视、轻微点头和光点；停止输入约 3 秒后恢复。检测只使用按下活动，不读取输入文字。

声音回应检测的是电脑的**输出音量**，默认跟随系统输出设备。播放音乐、视频或系统声音时会出现侧耳、点头和音符。可在 **互动 → 互动检测与效果预览** 查看检测状态、实际输出音量，并选择需要监听的输出设备。这里的设备选择只改变桌宠监听的对象，不改变 Windows 的默认输出设备。

睡觉、拖动和清理等动作会暂时抑制回应；攀爬、秋千保留支撑手，使用较轻的头部回应。打开性能详情只暂停人物位移，仍可回应输入。主动暂停或隐藏桌宠会暂停回应。

检测面板中的预览按钮用于逐项查看枫叶、音符、眼镜、星光、爱心、气泡、花瓣、风纹和尘点。预览成功并不代表收到真实输入；检测状态和音量读数用于判断输入是否到达。眼镜预览需要人物在地面，避免与支撑动作冲突。

## 清理内存

右键 → **性能与内存 → 立即清理内存**，或在性能详情中点击清理。已有效授权时直接执行；缺少授权时，只有主动清理或选择“修复清理授权…”才会请求 Windows 管理员授权。取消授权后不会自动反复弹出。

清理时显示当前步骤；重复点击不会覆盖本次请求。六项清理结束并核验后台退出后，才报告成功并出现完成闪光。部分失败、超时、主动取消和后台未退出分别显示；详情可查看各项结果。可用内存变化取自本次实测，数值不会固定，也可能因其他程序同时使用内存而减少。

系统通知之外，人物气泡和性能详情也会显示结果。自动清理保留至少 10 分钟的尝试间隔，失败不会触发密集重试。

## 暂停后拖放

右键选择“暂停活动”后，仍可拖动人物。拖到左右边缘显示静态攀爬姿势，拖到顶部显示静态秋千姿势；角落优先顶部。松手吸附后仍保持暂停，需要选择“继续活动”才会恢复。

## 文件和回滚

验收通过后分享完整 ZIP，接收方解压整个目录并运行其中的 `CuteMaple-Live2D.exe`。旁边的 `assets`、`web`、`cleaner` 和依赖文件必须保留，不能只发 EXE。

现有 v4 快捷方式和候选 ZIP 保留为回滚入口。v5 不重置个人设置；普通桌宠进程保持普通用户权限，清理助手单独获得按需授权。
