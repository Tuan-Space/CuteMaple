# 美腻枫 Live2D 桌宠

保留整个 `CuteMaple-Live2D` 文件夹，双击其中的 `CuteMaple-Live2D.exe` 即可启动。运行桌宠不需要打开 Cubism Editor。请以普通用户身份启动；首次启动默认关闭开机启动和自动清理。

- 默认待机并看向鼠标。右键桌宠 → **互动**，可单独开关视线跟随、自主行走、打字回应、系统声音回应和装饰特效。
- 拖到屏幕左、右边缘会侧身攀爬；爬到顶部会经过登顶动作再坐上秋千。拖到顶部也可进入秋千。
- 单击说话、双击开心；不按鼠标键，在头部左右来回扫动可触发抚摸。攀爬或荡秋千时会保持扶墙、握绳姿势。
- `Ctrl + 鼠标滚轮` 调整大小；右键菜单可暂停、隐藏、恢复大小和退出。隐藏后点击系统托盘图标恢复。
- 系统声音回应读取输出音量，不使用麦克风。打字回应只检测活动，不记录输入内容。
- 性能按钮单击查看本机内存和网络详情，双击执行清理。首次主动使用清理功能时，独立清理助手会请求授权。

个人设置及诊断日志保存在 `%APPDATA%\美腻枫`。首次升级旧版设置时会先备份，新版的开机启动和自动清理默认关闭；清理需要重新手动授权，其他互动偏好按迁移规则保留。

转身采用相邻视图淡化，交接时仍可能短暂重影，暂停恰好落在交接处时也会保留该画面。实际测试范围与其余限制以同包的 `RELEASE-VERIFICATION.json` 为准；只有候选状态的构建不代表已完成最终验证。
