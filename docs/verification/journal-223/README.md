基于 `a46364f`（2.2.2），分支 `codex/journal-polish-2-2-3`。采用清爽浅蓝手账风格，保留深色主题。

## 完成内容

- 安装器和设置页统一使用“开机自动启动”，移除左上角枫叶、品牌文字和占位。
- 待办橙、日程蓝、纪念日紫、笔记玫红、健康绿；图例、日期标记和条目类型标签一致。圆点按实际数量居中，10–12 月完整显示；切换月份同步选中日期与右侧详情。
- 五个主页面及辅助窗口统一纸白内容区、浅蓝灰背景、细分隔线和选中态。长标题换行；设置按资料与备份、应用、录音分组；统计突出数字、进度与明细。
- 标题、导航、分区标题与空态使用内置雅痞（Yuppy SC），正文、日期、数字使用清晰的微软雅黑。正式程序和截图工具共用字体初始化。
- 笔记支持正文／H1–H3、粗体、斜体、删除线、无序／有序列表、缩进、引用、链接、撤销与重做，支持 Ctrl+B、Ctrl+I。小窗口工具栏换行，正文、附件和录音面板保留各自空间。
- Markdown 存储保持不变，源码模式隐藏格式工具，复杂扩展原文保护禁用不安全格式操作。首次可视编辑保留原稿；在自动保存前快速切换源码仍保留备份意图。
- 音频播放完显示“重新播放”，之后外部点击或窗口失焦收起并清空音源。内部点击、重播、暂停、正在播放、切换笔记、关闭窗口和录音停止分别处理。
- 长提醒气泡在小屏幕内滚动正文，操作按钮始终留在可见区域。
