## 资料与源码

首次正常打开请选择独立于安装目录的资料文件夹。SQLite、笔记和附件一起保存在这里；完整备份包含附件。卸载不会删除资料库。测试安装对原有开机启动项和快捷方式的修改在验收结束后恢复。

源码包使用实际素材文件，不是 LFS 指针。可编辑 CMO 采用与运行模型配套的已提交版本；本地用户未提交 CMO 原件不覆盖、不提交，SHA256 保持 `d44c5856b839a716beb2b8d4e55b08254010c0e02d565f321494343ef5e8328a`。运行 MOC、纹理与动作未改动。

源码包的 `FILE-HASHES.json` 校验包内文件；安装 EXE 和源码 ZIP 均有独立 SHA256 文件。安装构建脚本、依赖版本和许可随源码提供。
