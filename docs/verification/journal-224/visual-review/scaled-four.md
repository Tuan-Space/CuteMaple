# 2.2.4 scaled four-set visual acceptance

Inspected all 212 PNG UI frames: dark 125%, 150%, 200%, and light 125% (53 per set). No open visual issues after the authorized disclosure-icon correction.

The first pass identified an uninitialized pixmap behind the More settings chevron. The local transparent-pixmap fix was rechecked in refreshed event/anniversary bottom frames at all four scales. Eight editor frames per set were refreshed; the remainder were unchanged.

All 36 base contact sheets were viewed. Four additional recapture sheets cover dark 125%/150%; dark 200%/light 125% base sheets were regenerated before review. Representative originals were checked for the repaired arrow. Contact-to-file mapping is in scaled-four-contact-index.json; the JSON audit records a SHA-256 for every final reviewed PNG.

Checked normal/small layout, advance checkboxes, month labels and markers, Today button, static/action distinction, batch selection and confirmation, read-only content, error focus/footer, save/cancel/close visibility, toolbars, text contrast and scrolling. Partial content at the scroll viewport edge is expected, with footer actions remaining visible.

The EventEditor focused suite passed 21 tests after the authorized icon and finite-rule rescheduling fixes. Visual acceptance covers rendered frames; runtime interaction coverage is supplied by those tests and the parent regression suite.
