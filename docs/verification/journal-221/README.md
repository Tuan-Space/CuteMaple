# 美腻枫 2.2.1 本地验证

本轮重做手账界面，新增纪念日里程碑；不修改 Live2D 模型，不执行真实内存清理，不上传 GitHub。

## 改动

- 左侧导航、系统字体、明暗配色和收起的高级设置。小窗口调整健康提醒与月历布局，无常驻翻页按钮。
- 提醒与笔记按批加载，空列表、单条和多批数据不显示无效翻页操作。录音及附件按需显示，删除与发生记录放在事件详情中。
- 月历同时显示待办橙、日程青、纪念日紫、笔记蓝、健康绿；右侧显示类型文字。历史发生使用当时名称，删除计划不再显示已取消的未来安排。
- 独立纪念日表单：每周年、每 100 天、520／1314 天、自定义天数。起始日算第 1 天，同日命中合并，调度与月历使用同一日期计算。
- 安装器、软件菜单和设置统一显示“开机自动启动美腻枫”。
- SQLite 升级到版本 2 前保存数据库快照；旧的普通纪念日规则不自动转换。

## 已验证

- 198 项相关自动回归通过。覆盖起始日、第 100／200／520／1314 天、自定义天数、周年、月底、闰年、农历闰月、DST、同日合并、提前／延期、逐次完成、重启补报和资料库迁移。
- 零条、1／50／51／101 条列表、滚动加载、搜索、未保存笔记、同日多类型、类型筛选、历史名称保留及取消未来安排。
- 提醒写入失败时保留待回应内容，错误提示经过刷新仍可见；只有多条提醒显示切换控件。
- 明暗主题与 100%、125%、150%、200% Qt 缩放截图；五个页面及事件／纪念日编辑，620×420 小窗口页面无横向溢出。生产程序截图另行保存，不以离屏截图代替生产启动。
- 最终编译程序实际打开五个页面与纪念日编辑，Live2D 首帧就绪。深色 UI 检查通过，浅色 UI 无错误。
- 最终程序实际录音 2.15 秒并保存到隔离笔记；播放器进度正常、无播放错误。私密测试录音不进入交付资料。
- 在新的中文、空格路径安装，逐文件核对与目录包一致；桌面快捷方式和开机启动项正确。卸载后原有快捷方式与启动项恢复，原有进程保持运行。
- Windows Defender 实时防护保持开启，最终程序、助手和安装 EXE 扫描无本次新增检测。该结论仅适用于记录中的环境与签名版本。
- 原生助手 2.2.1 无权限诊断通过，未执行任何系统清理。31 个运行源码模块与编译快照一致。

## 边界与待自测

- 当前系统默认 USB 扬声器静音。硬件报告的 `passed=false` 源于未检测到实际可听输出；录音、播放进度及静音后恢复入睡计时均已验证。取消静音后的音乐、输出设备切换仍需真实使用确认，本轮没有修改系统音量。
- 本轮保留用户正在运行的旧版，未对它进行运行中覆盖安装或强制退出。覆盖升级退出协议沿用 2.2.0；本轮只做隔离新安装与卸载。
- 资料库迁移使用隔离旧版数据库测试，未直接打开或修改个人资料库。长期使用、ToDesk 人工操作和多屏实际拖动留待用户确认。
- 不重新认证旧模型的全部动作或真实系统清理；模型、动作及清理协议保持原样。
