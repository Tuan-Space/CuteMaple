## 修改

- 清理的检查、授权提示、进度和结果统一显示人物气泡，删除 Windows 托盘通知调用。真正的 UAC 确认框保留，清理助手和授权协议没有改动。
- 进行中保持单个气泡；重复状态不会延长终态展示时间。成功显示 6 秒，错误或取消显示 8 秒。普通闲聊不能覆盖清理反馈，隐藏恢复尊重结果期限，气泡跟随人物并适配明暗主题。
- 修正四个连续摆动参数的精度：`ParamSwing`、`ParamAngleZ`、`ParamLegLA`、`ParamLegRA`。两份可编辑 CMO 与生成器均已更新，用户使用 Cubism 原生导出 MOC。
- 当前 CMO 的其他 XML 内容和内嵌贴图逐字节保持不变；运行模型的身份、UV、拓扑、蒙版和三个原有摆动关键姿态保持一致，纹理没有替换。
