# 美腻枫 2.2.2 本地验收

## 本轮结果

- 浅蓝／深蓝灰手账，总览为首个入口；枫叶标识、分段筛选按钮、统一箭头和明确的回收站状态。
- 总览支持年月选择、独立回到今天、淡化跨月日期、五类圆点、常用节日、休班角标与右键操作。长标题在当天详情换行。
- 年月日、时分秒两排填写，公农历直接切换；农历显示中文月日、合法闰月与天数。只读时区栏移除，原提醒时区保留。
- 打开、编辑及关闭手账不暂停人物。附件复制、录音附件导入及完整备份在后台处理。
- 提醒区分进行中、已完成和回收站；支持恢复、永久删除及周期单次排除。数据库迁移到版本 3 前备份，旧主动删除由审计记录识别；其他旧归档保留为已完成。
- 笔记正文可直接编辑，保留 Markdown 源码入口；复杂扩展语法按原文保留，首次格式转换编辑保存原稿。右下角“＋”提供附件和录音。
- 录音面板可收起，录制时仍显示状态与停止按钮。保存未完成时阻止切换笔记或进入回收站，避免禁用录音停止控件。

- `final222-*`：浅／深色 × 100%、125%、150%、200% 截图，包括所有页面、农历表单、回收站以及 620×420 小窗口。各页面横向溢出为零。小窗口通过纵向滚动展示完整内容。
