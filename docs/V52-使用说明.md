# 美腻枫 v5.2 使用说明

完整解压 ZIP，运行 CuteMaple-Live2D 文件夹里的 CuteMaple-Live2D.exe。发送给别人时发送整个 ZIP，不要只发 EXE。旧 v4、v5、v5.1 归档和个人设置保留。

- 清理与人物动作分开：不再取刷、扫尘或播放清理成功闪光，不打断睡眠、拖动、追视或秋千抚摸。
- 每次打开桌宠后，第一次主动清理会申请一次 Windows 管理员授权；本次运行后续清理复用授权。退出桌宠后授权结束。尚未授权时自动清理不会弹 UAC。
- 点击清理立即显示检查、授权或执行进度；重复点击显示当前操作。助手缺失、Windows 防护阻止、授权取消和执行失败分别显示。
- 贴到左右墙边后等待 30 秒，再连续爬两个完整周期，然后重新等待。等待时身体、裙袖、手脚固定，头眼轻微活动并跟随鼠标。到顶部仍转为秋千。
- 打开详情面板会冻结攀爬相位和位移，关闭后接着进行。主动暂停、隐藏也冻结等待时间；拖离墙边后重新贴边会重新等待。

此包已完成相关自动回归、原生播放器左右等待/攀爬录制与画面检查；具体证据见 QA。真实 UAC 接受/拒绝、六项系统清理、ToDesk 实际操作以及长期使用按约定由你自测。

Windows 防护保持开启。本次取消了常驻清理计划任务，但这不等于已证明防护问题解决。如果新助手被阻止，界面会报告失败；不要恢复隔离文件或添加白名单。清理可用性以你的真实清理结果为准。

本轮复用现有模型和可编辑工程，无需再次 Cubism 导出。历史清理素材保留在模型/工程归档中，桌宠运行入口已禁用。
