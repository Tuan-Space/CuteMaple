# 美腻枫 v5.2.1 使用说明

完整解压 ZIP，运行 CuteMaple-Live2D 文件夹内的 CuteMaple-Live2D.exe。分享时发送完整 ZIP，不要单独发送 EXE。旧版本与个人设置保留。

本轮更新：
- 详细面板、简洁面板、圆形监控按钮、自动清理设置统一跟随 Windows 应用明暗主题；运行中自动更新。
- 修复网速、清理按钮和关闭“×”不可见，统一背景、边框、文字、按钮状态、下拉箭头和勾选标记。长内容在空间不足时滚动，关闭和清理按钮留在固定位置。
- 两侧攀爬的 30 秒等待期间，脸平滑转为斜正面，继续眨眼和跟随鼠标；攀爬时再转回侧面。身体支撑姿势及两周期计时保留。

主题和动作均无需新增设置；本轮没有修改 CMO/MOC 或纹理，无需再次 Cubism 导出。

清理仍采用本次运行会话授权。真实 UAC、系统清理和长期使用按约定由你自测；本轮没有修改清理助手、防护设置或恢复隔离文件。详细测试范围见 QA。
